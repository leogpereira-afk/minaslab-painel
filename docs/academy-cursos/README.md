# Modelos de curso da Academy

Cada `.json` desta pasta é um **rascunho importável**: no editor do treinamento, aba Conteúdo, botão "Importar modelo (.json)". Depois é só revisar, definir o responsável e salvar. Nada aqui é publicado sozinho.

> **Atenção:** este repositório é público (ver README principal). Guarde aqui apenas conteúdo que pode ser público, como o de Gestão do Tempo. **Procedimentos técnicos da MinasLab, gabaritos de prova e dados de pessoas não devem ser commitados**; esses entram direto pelo sistema.

## Gestão do Tempo (`gestao-do-tempo.json`) — rascunho v1
- 5 módulos, 11 aulas, cerca de 94 minutos de atividades (soma das durações estimadas).
- Categoria sugerida: Gestão do tempo e desenvolvimento.
