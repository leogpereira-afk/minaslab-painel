# Modelos de curso da Academy

Cada `.json` desta pasta é um **rascunho importável**: no editor do treinamento, aba Conteúdo, botão "Importar modelo (.json)". Depois é só revisar, definir o responsável e salvar. Nada aqui é publicado sozinho.

> **Atenção:** este repositório é público (ver README principal). Guarde aqui apenas conteúdo que pode ser público, como o de Gestão do Tempo. **Procedimentos técnicos da MinasLab, gabaritos de prova e dados de pessoas não devem ser commitados**; esses entram direto pelo sistema.

## Gestão do Tempo (`gestao-do-tempo.json`) — rascunho v1
- 5 módulos, 11 aulas, cerca de 94 minutos de atividades (soma das durações estimadas).
- Categoria sugerida: Gestão do tempo e desenvolvimento.
- Conteúdo geral escrito como ponto de partida; **não contém procedimentos da MinasLab**.
- Inclui 3 atividades práticas (autodiagnóstico, plano da semana, compromisso pessoal) e 2 estudos de caso. Elas não comprovam competência sozinhas; servem de conversa com o gestor.

### Para o responsável pelo conteúdo decidir
1. Quem é o responsável pelo conteúdo (obrigatório para publicar).
2. O curso é obrigatório? Para quem (cargo, setor ou todos) e com qual prazo?
3. Tem reciclagem periódica? (Sugestão: sem validade.)
4. Carga horária: informar só se for validada pela Qualidade; por padrão fica em branco.
5. Trocar os exemplos genéricos por situações reais da rotina (atendimento, coleta, laboratório, administrativo).
6. Prova com nota mínima: será configurada na Etapa 3 (as questões e o gabarito serão cadastrados no sistema, não no repositório).
